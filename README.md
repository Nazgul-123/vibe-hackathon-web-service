# 🌠 Constellation Diary

**Constellation Diary** — это визуальный трекер задач, где каждая неделя превращается в созвездие.
Добавляй задачи как звёзды, соединяй их линиями и наблюдай, как формируется твоя личная галактика продуктивности ✨

---

## 🚀 Запуск проекта

### 1. Установи зависимости

Убедись, что у тебя установлен Python 3.10+
Затем в терминале выполни:

```bash
pip install -r requirements.txt
```

### 2. Запусти приложение

В каталоге проекта запусти:

```bash
python app.py
```

После запуска появится сообщение вроде:

```
 * Running on http://127.0.0.1:5000
```

Открой этот адрес в браузере.

## 🧭 Структура проекта

```
constellation-diary/
├── app.py                 # Flask-приложение (серверная логика и API)
├── requirements.txt       # Список зависимостей
├── static/
│   ├── css/style.css      # Стили интерфейса
│   └── js/                # Скрипты приложения
│       ├── app.js         # Основная логика
│       ├── canvas.js      # Работа с canvas (созвездие)
│       └── animations.js  # Анимации и эффекты
└── templates/
    └── index.html         # Главная страница
```

## ✨ Основные возможности

* Добавление задач как звёзд на небе
* Отметка выполненных задач
* Настроение недели (5 уровней)
* Завершение недели с анимацией
* Подсчёт streak 🔥
* Просмотр прошлых недель и галактики месяца
